# Moodle (plateforme de cours en ligne)

> Concerne : enseignants et étudiants.
> Dernière mise à jour : septembre 2026.

## Dans quels cas utiliser cette procédure

Utilisez cette procédure si :
- vous n'arrivez pas à vous connecter à Moodle ;
- votre cours n'apparaît pas dans Moodle ;
- vous voulez inscrire des étudiants dans votre cours ;
- vous voulez créer un devoir ou un test (quiz) ;
- un fichier est trop lourd pour être déposé ;
- vous voulez réutiliser votre cours de l'année dernière.

## Se connecter à Moodle

1. Ouvrez https://moodle.ecole.example.
2. Cliquez sur « Connexion avec l'ENT ».
3. Saisissez votre identifiant ENT (prenom.nom) et votre mot de passe.

Si la connexion est refusée, le problème vient de votre compte : suivez la procédure « Mot de passe oublié ou compte bloqué ».

## Pour les enseignants

### Mon cours n'apparaît pas

Les cours sont créés automatiquement à partir de l'emploi du temps, 2 semaines avant le début du semestre. Si votre cours n'apparaît toujours pas, ouvrez un ticket dans la catégorie « Moodle » en indiquant l'intitulé du cours, son code et le semestre.

### Inscrire les étudiants

- Les étudiants des groupes prévus à l'emploi du temps sont inscrits automatiquement.
- Pour ajouter une personne à la main : dans votre cours, allez dans « Participants », puis « Inscrire des utilisateurs ».
- Vous pouvez aussi créer une clé d'inscription : « Participants », puis « Méthodes d'inscription », puis « Auto-inscription ».

### Créer un devoir ou un test

1. Dans votre cours, activez le « Mode édition » en haut à droite.
2. Dans la section voulue, cliquez sur « Ajouter une activité ou une ressource ».
3. Choisissez « Devoir » pour un rendu de fichier, ou « Test » pour un quiz.
4. Réglez les dates d'ouverture et la date limite de rendu, puis enregistrez.

### Fichiers lourds et vidéos

- Un fichier déposé sur Moodle ne peut pas dépasser 100 Mo.
- Les vidéos ne doivent pas être déposées sur Moodle : publiez-les sur le serveur vidéo de l'école (https://video.ecole.example), puis ajoutez le lien dans votre cours.

### Réutiliser un cours de l'année précédente

Dans votre nouveau cours, allez dans « Plus », puis « Réutilisation de cours », puis « Importer », et choisissez l'ancien cours.

## Pour les étudiants : déposer un devoir

1. Ouvrez le devoir dans votre cours et cliquez sur « Ajouter un travail ».
2. Déposez votre fichier, puis cliquez sur « Enregistrer ».
3. Si le bouton « Envoyer le devoir » apparaît, cliquez dessus : sinon, votre devoir reste à l'état de brouillon.

Après la date limite, le dépôt est fermé. Seul l'enseignant peut accorder une prolongation.

## Problèmes fréquents

- Page blanche ou erreur : videz le cache de votre navigateur ou essayez un autre navigateur.
- Dépôt refusé : vérifiez la date limite et la taille du fichier.

## Se former à Moodle

La DSI organise un atelier Moodle pour les enseignants chaque mois. L'inscription se fait depuis l'ENT, rubrique « Formations ».

## Si ça ne fonctionne pas

- Ouvrez un ticket sur https://support.ecole.example (catégorie « Moodle ») ou écrivez à dsi@ecole.example.
- Bureau de la DSI : bâtiment A, salle A012, du lundi au vendredi de 8 h 30 à 17 h.
