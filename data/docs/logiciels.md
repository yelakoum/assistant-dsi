# Installer un logiciel ou obtenir une licence

> Concerne : enseignants, personnel administratif et étudiants.
> Dernière mise à jour : septembre 2026.

## Dans quels cas utiliser cette procédure

Utilisez cette procédure si :
- vous voulez installer un logiciel sur un ordinateur de l'école ;
- vous avez besoin d'un logiciel dans une salle informatique pour vos TP ;
- vous voulez une licence gratuite pour votre ordinateur personnel (Microsoft 365, MATLAB) ;
- votre ordinateur vous demande un mot de passe administrateur.

## Sur un ordinateur de l'école

Pour des raisons de sécurité, les utilisateurs n'ont pas les droits administrateur sur les ordinateurs de l'école.

1. Ouvrez le « Centre logiciel » (icône sur le bureau).
2. Cherchez le logiciel dans le catalogue et cliquez sur « Installer ». Aucune demande n'est nécessaire pour les logiciels du catalogue.
3. Si le logiciel n'est pas dans le catalogue, ouvrez un ticket dans la catégorie « Logiciel », en indiquant son nom, sa version et l'usage prévu. La DSI vérifie sa sécurité et sa licence : comptez 5 jours ouvrés.

## Logiciels pour les salles informatiques (TP)

Les logiciels des salles informatiques sont installés avant le début de chaque semestre. Faites votre demande :
- avant le 1er juillet pour le semestre 1 ;
- avant le 15 décembre pour le semestre 2.

Indiquez le nom du logiciel, sa version, les salles concernées et le nombre de postes. Après ces dates, l'installation n'est pas garantie pour le semestre.

## Licences pour votre ordinateur personnel

- Microsoft 365 (Word, Excel, PowerPoint, Teams) : jusqu'à 5 appareils. Activez-le depuis https://moncompte.ecole.example, rubrique « Logiciels ».
- MATLAB : licence campus. Créez un compte sur le site de l'éditeur avec votre adresse @ecole.example.
- Ces licences sont valables tant que vous faites partie de l'école. Elles expirent à votre départ.

## Ce qui est interdit

- Installer des logiciels piratés ou « crackés », sur un ordinateur de l'école comme pour un usage lié à l'école.
- Contourner le Centre logiciel pour installer un logiciel non validé.

## Si ça ne fonctionne pas

- Ouvrez un ticket sur https://support.ecole.example (catégorie « Logiciel ») ou écrivez à dsi@ecole.example.
- Bureau de la DSI : bâtiment A, salle A012, du lundi au vendredi de 8 h 30 à 17 h.
